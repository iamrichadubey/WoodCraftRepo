# WoodCraft Studio

A made-to-measure furniture customization studio for Indian homes, powered by an ASP.NET Core minimal API.

## Architecture

The app uses a lightweight layered design: HTTP endpoints handle transport, services contain furniture rules and validation, and the repository interface isolates SQLite persistence. `Program.cs` is the composition root where dependencies are registered.

- `Api/` maps HTTP routes to application services.
- `Services/` contains design generation, validation, and the furniture catalog.
- `Data/` contains the repository contract and SQLite implementation.
- `Models/` contains API and persistence records.
- `wwwroot/js/catalog.js` owns browser catalog and formatting data; `api.js` owns HTTP requests; `app.js` handles page interactions and rendering.

## Requirements

- .NET 10 SDK

## Run

From this directory, run:

```sh
dotnet run
```

Open the local URL printed by ASP.NET Core. Choose a bed, cupboard / wardrobe, office furniture, or home mandir; set its shape, dimensions in centimetres, colour, design changes, and budget in Indian rupees. `POST /api/designs/generate` returns three options with indicative INR price ranges and budget-fit status. **Save to project** stores the selected setup in **My projects**, where it remains available after restarting the app. **Save idea** separately adds or removes it from favorites. `GET /api/projects` lists projects, and `GET /api/health` reports the service status.

## GitHub Pages demo

The `static-pages` branch publishes a static demo at <https://iamrichadubey.github.io/WoodCraftRepo/> through GitHub Actions. It supports browser-based design previews and the Discover catalog. GitHub Pages cannot run the ASP.NET API or SQLite database, so project and favorite saving are available only in the full app.

Use **Discover** to browse the standard display collection (three designs each for beds, cupboards, office furniture, and home mandirs) without entering customization details. Each design shows its furniture type's standard base price; confirm current display availability and final pricing with Balaji Enterprises.

The database is created as `woodcraft.db` in the project directory on first run. Remove projects from **My projects** or use `DELETE /api/projects/{id}`. Click **Saved** again on a saved setup to remove it; the `DELETE /api/designs/saved/{id}` endpoint is also available.

Cost figures are rough planning estimates, not quotes; material grade, hardware, local workmanship, and location affect final pricing. The design form has a browser-only preview fallback when opened directly without the .NET server. Concept descriptions and estimates are generated by local rules; connecting an external AI image-generation service requires a separate provider and credentials.

## Choose furniture images

In `wwwroot/js/app.js`, each entry in `furnitureTypes` has an `images` array. The three entries map to the three concept cards; clicking a card selects it in the main preview.

To use your own photos, place them in `wwwroot/images` and use their paths in the array, for example:

```js
images: [
	"/images/bed-front.jpg",
	"/images/bed-storage.jpg",
	"/images/bed-side-view.jpg"
]
```

You can also use direct image URLs. Local files are served by ASP.NET Core from `wwwroot`.
